# EmployeeDBApp

Salary form is generated by doGet. Run database/setup.sql first. Uses init, doGet, doPost, destroy.

Compile and package from this application's folder in PowerShell:
```powershell
javac --release 8 -cp "$env:CATALINA_HOME\lib\servlet-api.jar" -d "webapp\WEB-INF\classes" "src\SalaryServlet.java"
jar -cvf EmployeeDBApp.war -C webapp .
Copy-Item "EmployeeDBApp.war" "$env:CATALINA_HOME\webapps\" -Force
```
URL: `http://localhost:8080/EmployeeDBApp/`
