THREE WAD PRACTICE PROJECTS

1. library-borrowing.zip — Library Book Borrowing Management System
2. event-registration.zip — Event Registration Management System
3. course-registration.zip — Course Registration Management System

Each ZIP contains QUESTION.txt, README.md, backend source (Spring Boot + Maven + MongoDB + MockMvc test), and frontend source (React + Vite). No node_modules or compiled build files are included.

Prerequisites: JDK 17+, Maven, MongoDB running on localhost:27017, Node.js.
Backend: open the backend folder and run `mvn spring-boot:run`
Tests: open the backend folder and run `mvn test`
Frontend: open the frontend folder and run `npm install`, then `npm run dev`

These are practice starter projects. Run the tests and review the code locally before using them for submission.
